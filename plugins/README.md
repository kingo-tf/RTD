# Warning

The SMX binary in this folder is unstable and not supported. **Use at your own risk**.

It is built from this fork and needs the `game.tf2r.ext` extension from [kingo-tf/sourcemod](https://github.com/kingo-tf/sourcemod). It does not load on a regular Team Fortress 2 server.

To get the original RTD for regular Team Fortress 2, download one of the releases from [here](https://github.com/Phil25/RTD/releases/).
